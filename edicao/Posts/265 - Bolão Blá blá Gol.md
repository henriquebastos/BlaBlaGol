# Bolão Blá blá Gol

A forma mais simples é fazer mesmo como Loteria Esportiva. Acertar quem vence ou se dá empate.

À princípio computarei um ponto para cada resultado certo, como há dois anos (e agora entrando no terceiro) vem fazendo [Lédio Carmona em seu blog](<https://web.archive.org/web/*/http://www.ledio.globolog.com.br/> "Captura ainda não verificada. Endereço original: http://www.ledio.globolog.com.br/").

Depois, se o Excel me permitir, faço uma papagaiada com um possível 2º prêmio (será que chegamos lá?). Aí contabilizamos os resultados pela porcentagem de votos (basicamente, se alguém acertar uma zebra, ganha mais pontos).

Para que se animem de entrar depois do campeonato já começado, fica valendo também uma regra meio de apuração de escola de samba. Das 38 rodadas, as 8 piores serão descartadas, incluindo aí as não jogadas.

O [tópico abaixo](<https://web.archive.org/web/*/http://blagol.blogspot.com/2007/05/bolo-1-rodada.html> "Captura ainda não verificada. Endereço original: http://blagol.blogspot.com/2007/05/bolo-1-rodada.html") fica para os palpites do pessoal.

Bender, não use seus pseudônimos para os palpites.
